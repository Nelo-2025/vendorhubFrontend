# Trackly

Inventory management for online sellers. Track stock levels, sync across sales channels, and stay ahead of restocks — all from one place.

## Overview

Trackly helps online sellers keep accurate, up-to-date inventory without the spreadsheet chaos. Whether you're selling on one marketplace or five, Trackly gives you a single source of truth for what you have, what's low, and what's selling.

## Features

- Centralized inventory — manage stock levels for every product in one dashboard
- Multi-channel sync — keep quantities consistent across marketplaces and storefronts
- Low-stock alerts — get notified before you run out of your best sellers
- Sales history — see how fast items move so you can plan restocks with confidence
- Bulk import/export — update inventory in bulk via CSV
- Simple, fast UI — built for sellers, not accountants
